MT5 EA + Custom Indicator

This repository includes:

  • mt5/Experts/EMA_Cross_EA.mq5
  • mt5/Indicators/EMA_Cross_Arrows.mq5

Android MT5 Limitation

MT5 Android cannot run EAs or custom indicators directly. Run them on MT5 Desktop or MQL5 VPS, then monitor and manage trades from Android.

Strategy Included

Both files use an EMA crossover model (default 20/50). The EA can open/close trades on crossover; the indicator plots buy/sell arrows.
